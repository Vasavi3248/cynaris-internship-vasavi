# SQL Fundamentals — Week 1, Day 1

## Overview
This beginner project practices SQL `SELECT`, `FROM`, `WHERE`, `AND`, `OR`, `NOT`, `LIKE`, `IN`, `BETWEEN`, and `IS NULL` using a sample sales database structure.

## Files
- `queries_day1.sql` — 10 practice queries.
- `sales_results.csv` — example CSV export for query 9.

## Assumed tables
The queries assume these tables exist:
- `customers(customer_id, customer_name, city, email)`
- `products(product_id, product_name, category, price, stock)`
- `orders(order_id, customer_id, order_date, status, total_amount)`

**Important:** These are practice queries based on an assumed schema. If your internship platform provides a specific database or table names, adjust the queries to match it. The included CSV is sample output, not a live database export.
