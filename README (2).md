# Day 5 – Python for Data: Pandas Basics

## Objective
Perform exploratory data analysis (EDA) and basic data cleaning using Pandas.

## Dataset
This notebook uses the public Titanic CSV dataset from the Seaborn example-data repository:
https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv

If your internship has provided a different dataset, update `DATA_URL` in the notebook or replace it with the local CSV path.

## Requirements
- Python 3
- pandas
- Jupyter Notebook

Install the packages:
```bash
pip install pandas notebook
```

Start Jupyter:
```bash
jupyter notebook
```

Open `analysis_day5.ipynb` and run the cells from top to bottom.

## Tasks covered
1. Load a CSV into a Pandas DataFrame.
2. Inspect data with `head()`, `tail()`, `info()`, `describe()`, and `value_counts()`.
3. Select columns and filter rows.
4. Identify and handle missing values.
5. Group data and calculate aggregate metrics.
6. Export cleaned data to `titanic_cleaned_day5.csv`.

## Deliverable
`analysis_day5.ipynb` – Jupyter Notebook containing EDA on a real dataset.
