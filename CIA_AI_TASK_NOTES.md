## CIA question
**What are the most useful Pandas methods for exploratory data analysis?**

Pandas provides several useful methods for understanding a dataset:

1. `read_csv()` loads CSV data into a DataFrame.
2. `head()` and `tail()` display the first and last rows.
3. `shape` shows the number of rows and columns.
4. `info()` shows column names, data types, and non-null counts.
5. `describe()` provides statistical summaries such as count, mean, standard deviation, minimum, and maximum.
6. `value_counts()` shows the frequency of each category.
7. `isnull().sum()` counts missing values in each column.
8. `nunique()` counts unique values in columns.
9. `groupby()` groups rows by category for analysis.
10. `agg()` calculates multiple summary statistics.
11. `sort_values()` sorts rows based on one or more columns.
12. `corr()` helps examine correlations between numeric columns.
13. `to_csv()` exports the cleaned or analyzed data.

**Conclusion:** These methods help an analyst understand the structure, quality, distribution, and patterns in data before building reports or machine-learning models.
