## AI Tutor Insights
Common SQL mistakes include:
- Incorrect WHERE conditions.
- Misusing AND and OR.
- Using = NULL instead of IS NULL.
- Using SELECT * when unnecessary.
- Incorrect use of LIKE, IN, and BETWEEN.
- Failing to validate query results.

## Learning Outcome
