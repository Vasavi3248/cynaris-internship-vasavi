# Week 2 Day 2 – Pandas Advanced

## Overview
This project demonstrates advanced data manipulation techniques using the Python Pandas library.

## Practical Tasks

1. **DataFrame Merging:** Implemented Inner, Left, Right, Outer, and Cross joins.
2. **Pivot Tables:** Summarized sales data by region and product.
3. **Data Reshaping:** Converted wide-format data into long-format using `pd.melt()`.
4. **Method Chaining:** Performed multiple Pandas operations in a single sequence.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- Anaconda

## How to Run
1. Install Python and Pandas.
2. Open Jupyter Notebook.
3. Open `advanced_pandas.ipynb`.
4. Run all cells sequentially.

## Learning Outcomes
- DataFrame merging and joining.
- Data summarization using pivot tables.
- Data reshaping.
- Efficient data processing using method chaining.
