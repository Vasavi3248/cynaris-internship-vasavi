# Week 2 – Day 3: Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a Sales dataset containing 1,200 records.

## Dataset
- File: sales_data_1200_rows.csv
- Records: 1,200 rows
- Format: CSV

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed
1. Loaded and profiled the dataset.
2. Checked dataset shape, data types, missing values and duplicates.
3. Created distribution plots for all numerical columns.
4. Identified correlations using a heatmap.
5. Documented five business insights with supporting charts.
6. Generated a summary statistics table.

## Project Files
- eda_report.ipynb – Complete EDA workflow.
- sales_data_1200_rows.csv – Original dataset.
- summary_statistics.csv – Summary statistics.
- charts/ – Generated visualizations.

## Conclusion
Completed exploratory data analysis to understand sales data patterns, distributions, correlations and business insights.
